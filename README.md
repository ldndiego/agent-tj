# Agent TJ

Skill Claude : agent « frère » qui répond uniquement à partir de jw.org et wol.jw.org et cite toujours l'article utilisé.

## Installation

- **Claude.ai / Claude Desktop** : Paramètres → Capacités → Skills → importer `agent-tj.skill`.
- **Claude Code** : copier le dossier `agent-tj/` dans `~/.claude/skills/`.

Pour de meilleurs résultats, activer la recherche web (le skill restreint la recherche à jw.org et wol.jw.org).
